Prompt the model

Describe what you want in plain words. Quill reads your prompt, picks a starting point in its gene grammar, then writes DNA base by base - the same way it would predict it.

Quill has no language model. It matches these words to states and conditions in its grammar, and tells you above exactly what it understood.

What does this gene do?

Paste a coding sequence. The written weights score it against ten Gene Ontology slim classes and seven gene families. Nothing was trained: the amino acid composition, N-terminal targeting peptides, repeat periods, transmembrane helix length and coding length of each class were written down from memory, and these are the tables that follow from them.

Which kind of RNA is this?

Paste a non-coding transcript. 260 written parameters — the box C and D of a C/D snoRNA, the box H and ACA of an H/ACA snoRNA, the Sm site of a spliceosomal snRNA, the tRNA A and B boxes, plus a length, a GC fraction, an exon count and a self-pairing target per class — decide between ten Sequence Ontology classes.

Write a gene that does a particular job

Sampling runs the same tables backwards. A collagen comes out with glycine at every third residue, a zinc finger with its cysteines and TGEKP linkers, an olfactory receptor with hydrophobic helices crossing the membrane.

Hydrophobic residues are tinted, so a membrane protein shows its helices as blocks rather than as scattered colour.

How the experts are weighted

Quill mixes four predictors at every base. The weights were found by EM - 864 numbers, the only part of the model fitted by iteration rather than counted. Rows are states, columns are the four experts. Notice the matrices take over completely at splice sites and start codons, and the context model takes over in bulk DNA.

columns: context model · matrix / class table · codon model · uniform
